# Antigravity Cloud Capstone Pack

Giải nén toàn bộ nội dung zip này vào **root project ProShop MERN**.

Sau khi giải nén, cấu trúc sẽ có:

```text
ANTIGRAVITY_CLOUD_CAPSTONE_PLAN.md
skills/
└── cloud-capstone-proshop/
    ├── SKILL.md
    ├── ANTIGRAVITY_STARTER_PROMPT.md
    └── templates/
```

Cách dùng:

1. Copy/gắn các file này vào root project.
2. Mở Antigravity.
3. Dán nội dung trong `skills/cloud-capstone-proshop/ANTIGRAVITY_STARTER_PROMPT.md`.
4. Yêu cầu Antigravity làm tuần tự từng batch.
5. Sau mỗi batch, kiểm tra phần `Execution Status` trong `ANTIGRAVITY_CLOUD_CAPSTONE_PLAN.md`.
